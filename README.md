# Spotify India – User Engagement & Business Requirements Analysis

##  Project Overview

This project analyzes the user engagement challenges faced by Spotify in the Indian music streaming market.

The analysis uses **system thinking, competitive analysis, user segmentation, user personas, Jobs-to-be-Done (JTBD), user journey analysis, hypothesis framing, and Business Requirements Document (BRD)** techniques to identify key engagement gaps and define measurable product outcomes.

The project focuses on understanding **why users may not engage deeply with Spotify India and what business and product areas should be prioritized to improve engagement, retention, and premium conversion.**

---

##  Business Problem

Spotify India faces challenges related to user engagement, including:

- Shorter average session duration
- Lower user retention
- Low free-to-premium conversion
- Inconsistent regional content discovery
- Low playlist creation and social sharing
- Friction during onboarding and re-engagement
- Technical and connectivity constraints for some Tier-2/3 users

The objective of this project is to frame these challenges from a business and user perspective and define measurable requirements and success criteria.

##  User Personas

Four representative personas were developed to understand different user needs and engagement barriers.

### 1. Urban Gen Z Explorer
- Uses Spotify primarily on mobile
- Discovers music through social media
- Values music identity and social sharing
- Faces ad fatigue and recommendation relevance issues

### 2. Millennial Commuter
- Uses Spotify during daily commuting
- Values curated music and podcast discovery
- Faces regional content discovery gaps

### 3. Tier-2 User
- Uses Spotify occasionally
- Strong preference for Bollywood and regional content
- Faces connectivity, data usage, and UI complexity constraints

### 4. Young Professional Music Enthusiast
- Premium user with high listening time
- Creates playlists and collaborative lists
- Values artist discovery and social engagement

##  Current Engagement Gap

The BRD uses estimated Spotify India metrics and global benchmarks to frame the engagement gap.

| Metric | Spotify India (Estimated) | Global Benchmark |
|---|---:|---:|
| Average Session Length | ~18 min | ~26 min |
| DAU/MAU Ratio | ~15–18% | ~25–28% |
| 30-Day Free Retention | ~35–40% | ~50–55% |
| Free-to-Premium Conversion | ~3–5% | ~23–26% |
| Weekly Free Listening | ~3–4 hrs | ~6–7 hrs |
| Playlist Creation | ~8% of MAUs | ~18% of MAUs |

These figures are used as directional benchmarks within the project and are not presented as Spotify internal data.

##  Hypothesis Framework

The project defines hypotheses to guide future discovery and validation.

Examples:

### Hypothesis 1
If regional music recommendations are improved, Tier-2/3 users will spend **30%+ more time per session**.

### Hypothesis 2
If session continuity features reduce friction between songs, average session length will increase beyond **25 minutes**.

### Hypothesis 3
If social sharing is made frictionless, playlist creation and sharing will increase engagement by **2× among Gen Z users**.

These hypotheses are proposed for validation and should not be interpreted as confirmed causal findings.

##  Success Criteria & KPIs

The BRD defines measurable targets for evaluating future improvements.

| KPI | Estimated Baseline | 12-Month Target |
|---|---:|---:|
| Average Session Length | ~18 min | ≥24 min |
| DAU/MAU Ratio | ~16% | ≥22% |
| 30-Day Free Retention | ~38% | ≥50% |
| Free-to-Premium Conversion | ~4% | ≥7% |
| Onboarding Completion | ~55% | ≥75% |
| Playlist Creation | ~8% | ≥14% |
| Weekly Free Listening | ~3.5 hrs | 5 hrs |
| Regional Language Streams | — | +40% YoY |

The targets are directional and intended to be revised following further discovery research.

##  Key Business Recommendations

Based on the problem framing and analysis, the project identifies the following areas for product intervention:

- Improve regional content recommendations
- Personalize onboarding using richer user signals
- Improve session continuity and queue management
- Introduce context-aware re-engagement
- Improve social sharing and collaborative experiences
- Address data efficiency and low-end device constraints
- Strengthen music and podcast discovery
